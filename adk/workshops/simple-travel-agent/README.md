# Simple Travel Agent

This is a simplified version of the travel agent designed for a step-by-step workshop. It demonstrates the core concepts of the Agent Development Kit (ADK).

## Workshop Goals

By following the [`WORKSHOP.md`](WORKSHOP.md) guide, you will learn how to:

1.  Create a basic ADK agent.
2.  Implement custom Python tools (e.g., `now()`).
3.  Integrate pre-built tools (e.g., Google Search).
4.  Connect to external services using the Model Context Protocol (MCP).

## Getting Started

Make sure you have `uv` installed for dependency management.

```bash
# Install dependencies
uv sync
```

Start the workshop by following the instructions in [`WORKSHOP.md`](WORKSHOP.md).
